## 四、快速开始

1. **考插备考**：双击 `考插资料.bat` —— 只搜考插数学 + 考插英语资料（班表、真题、讲义）；
2. **华理课业**：双击 `课业资料.bat` —— 只搜华理课程课件、作业实验、考试与保研资料；
3. 拿不准就用 `查资料.bat`（自动判断域：出现「考插 / 插班生」走考插库，工具词走全库，其余走课业）；
4. **要一句话答案**（不是 5 条片段）：双击 **`问答案.bat`** —— 检索 + 多轮升级 + 带 `[编号]` 引用的答案 + 出处，资料里没有就直说没有（见下节）；
5. 前置条件：`Ollama` 必须在跑。没有它会自动尝试拉起，拉不起来会直接告诉你怎么做（不会抛一堆报错）。
6. 命令行单次检索：

```bat
py -3.12 -X utf8 kb_ask.py "大物实验 分光计 数据处理"
py -3.12 -X utf8 kb_ask.py "高数下 期末 历年真题" --mode turbo
py -3.12 -X utf8 kb_ask.py "马克思主义基本原理 复习重点" --json
py -3.12 -X utf8 kb_ask.py "sympy 怎么解方程" --scope all    # 指定检索域
```

| 档位 | 参数 | 说明 |
|---|---|---|
| fast（默认） | `--mode fast` | 本地模型改写 + 召回 + 两阶段重排，约 10~30 秒/次 |
| turbo | `--mode turbo` | 只做向量 + 关键词召回，1~2 秒/次，精度较低 |
| deep | `--mode deep` | 云端模型改写重排，约 1 分钟/次，需联网 |

交互模式支持：输入 `1..5` 直接打开结果文件；`m fast/deep/turbo` 切换档位；`s` + 域名单切换检索域（可用：auto / core / kaocha / gpa / kmath / ken / gmath / gen / gother / math / en / mathdoc / tech / all）；`t 知识点 [题型]` 列考插数学题；`h` 帮助；`q` 退出。

## 五、检索原理（简要）

多路召回（原句 + 中英改写 + 中文 BM25 + 英文分池保底）→ 加权 RRF 融合 → **域过滤（`scope` = core / kaocha / gpa / kmath / ken / gmath / gen / gother / mathdoc / tech / all，2026-09-20 22:40 重构）** → 本地两阶段重排（Ollama `qwen2.5:7b`）→ **元文件降权 / 文件名命中加成（2026-09-20 新增）**，向量模型为 `qwen3-embedding:0.6b`（1024 维，2026-09-20 换入；旧 `nomic-embed-text` 768 维在 `vector_store_v7`）。扫描件已用本地 RapidOCR（免费、离线）补齐文本。

> 元文件降权：`README` / `说明` / `快捷方式` / `.url` / `.lnk` 这类本身不含知识的文件乘 `0.4` 降权（`META_PENALTY`）；
> 文件名命中加成：问题里的词和文件名/路径重合度高时乘最高 `1.2`（`PATH_BOOST`）。两项都在重排后段生效。

## 五之二、问答入口（模范 RAG：`kb_answer.py`）

`kb_ask.py` 给「5 条片段」，**`kb_answer.py` 给「一段带引用的答案」**。对标 2024-2025 主流 RAG 的标准范式：

1. 第 1 轮检索 → 2. **证据体检**（纯启发式，不调 LLM，确定性零成本：词面覆盖率 ≥0.28 或最佳分 ≥8.5 判为足够）
→ 3. 不足则 **Agentic 升级最多 3 档**：① 换召回方式（关改写关重排，救被重排误杀的候选）② 扩检索域（**仅 `auto` 允许**，用户显式指定域时不擅自扩）③ 同文件深挖

## 五之三、MCP 接入（让别的 Agent 用这个知识库）

`kb_mcp.py` 是 **MCP stdio server**，暴露 5 个工具：`kb_search` / `kb_ask` / `kb_list_questions` / `kb_stats` / `kb_scopes`。
配置已写进 `~\.workbuddy\mcp.json`（server 名 `local-kb`），需在**连接器管理页 → 自定义连接器 → 点「信任」**后才生效。

> ⚠️ **stdio 协议纪律（最大坑）**：MCP 的 stdio 传输**自己就在 `sys.stdout` 上收发 JSON-RPC**。
> 用 `contextlib.redirect_stdout(stderr)` 包裹工具函数，会把响应写进 stderr → 客户端永远等不到 → **`list_tools` 正常但第一个 `call_tool` 直接死锁**。
> 正确做法：把各 kb 模块全局命名空间的 `print` 换成写 stderr 的版本（外科手术式），**绝不动 `sys.stdout`**。
