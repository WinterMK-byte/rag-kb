## 五、仍然存在的限制（别高估收益）

1. **数学 OCR 天生稀薄**。62 份扫描件合计只有 **429 KB** 正文（含标题头），而 `考插英语习题资料` 是 1441 片段。原因是数学卷面以公式/图像为主，OCR 只能捞到周边文字。**别指望数学变成和英语一样密的语料。**
2. **公式会失真**。OCR 出来的积分号、求和号、上下标多为残片（例：`(vdx-xdy)`），能佐题、不能替代原卷。
3. **`考研数学必备手册` 等 17 个文件保留的是旧缓存**（旧缓存更长），未走新 OCR。
4. **ECUST 课程资料仍有 188 个文件无有效正文**（工程/动画/图片型），属正常，不需补救。
5. **数学资料的检索主力应是题目库（`--kp/--type`），不是语义检索。** 向量库负责「顺着关键词找到那份资料」，题目库负责「列出这个知识点的题」。
