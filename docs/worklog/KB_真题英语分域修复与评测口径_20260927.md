## 二 · 根因：两处 `SCOPE_RULES` 错误叠加

### 错误 1：`ken` 规则目录名写错（规则空转）

```python
# 改前（kb_search_v4.py L747~750）
'ken': ('考插英语习题资料', os.sep.join(('真题', '英语真题')),
        os.sep.join(('插班生真题库', '英语真题集')),            # ← 磁盘上没这个名字
        os.sep.join(('插班生真题库', '各校插班生英语作文回忆版真题')))  # ← 也没这个名字
```
磁盘上实际目录是：
```
插班生真题库\【精讲班同学】英语真题集\        （51 文件）
插班生真题库\英语巩固讲义插班生资料\          （7 文件）
```
→ **两条规则都匹配不上任何文件 → `ken` 对真题库完全空转。**

### 错误 2：`kmath` 用了宽泛的 `'插班生真题库'`（把英语也吞了）

```python
# 改前 L745
'kmath': (..., '插班生真题库', ...)   # ← 整个目录，含英语子目录
```
→ 190 条英语真题**全被归到 `kmath`**（`scope_of` 实测：379 条真题 **100% 是 kmath**）。

**叠加后果**：英语真题既没被 `ken` 收（规则写错），又被 `kmath` 吞（宽泛规则）→ **查英语真题时一条都进不来**。

## 三 · 修复：逐个子目录精确登记

               os.sep.join(('插班生真题库', '21-25数学真题')),

## 五 · ⚠️ 关键发现：评测分数依赖重排缓存（方法论级）

修复后评测 **Hit@1 76.5% → 70.6%**。深挖后**排除了两次「看错因」的可能**，最终定位到两件事：

### 事实 1：同名同码、仅清缓存 → 分数就变（−3.0pt）

| 配置 | Hit@1 | MRR |
|---|---|---|
| v11 规则 + **旧缓存**（09-26 起）| **76.5%** | 0.853 |
| v11 规则 + **冷重排**（清空缓存）| **73.5%** | 0.833 |

→ **一模一样的代码，只清空 `rerank_cache_v4.json`，Hit@1 掉 3pt。**
→ 说明 `kb_eval.py` 的分数**依赖缓存命中**，`RR_SALT` 一升就必然掉。

### 事实 2：抖动只集中在 3 条，且都是「rank 1↔2↔3 临界」

三次跑的非 rank=1 条目交集 = `e01`（1↔2）、`m07`（2↔3）、`m12`（1↔3）。其余 31 条**完全稳定**。

### 同口径对照（v11 vs v12，都冷跑）

| 配置 | Hit@1 | 差异来源 |
|---|---|---|
| v11 规则 + 冷重排 | 73.5% | 基线 |
| **v12 规则 + 冷重排** | **70.6%** | **−2.9pt** |

### −2.9pt 的真因：`e01` 被新入 `ken` 池的真题挤位

`e01`（四级段落翻译）改后 top8：
```
1.   24-25寒假集训班 DAY2.pdf                      ← 老资料（不在 expect）
2. ★ 25翻译板书中翻英+整理新.pdf                     ← expect 命中
3. ★ 25精讲班孔老师第七天板书（翻译板书中翻英）.pdf      ← expect 命中
4. ★ 英语四六级考试段落翻译题.doc                     ← expect 命中
5.   真题库 IMG_0126.jpg                           ← 🆕 新入池的英语真题
6.   真题库 IMG_0116.jpg                           ← 🆕
```
**正确的文件依然在 top2/top4（都在 expect 里）**，只是没抢到第 1。
→ **`ken` 池 +190 条新真题后，重排的相对分布变化 → 正确项从 rank1 滑到 rank2。**
→ **这不是检索退化，是「新资料入池改变了竞争格局」的正常现象。**

### `m07` / `m12` 的下降 = 纯重排噪声

实测二者的 top8 **一条真题都没有**（全是「考插数学习题资料」+「ECUST课程资料」）——
即 `mathdoc` 池虽从 789 缩到 599（`kmath ⊂ mathdoc`，190 条英语真题移出），
**但真题本就不在这两条查询的候选里** → 它们的 rank 变化**与本次改动无关，纯属 LLM 重排的临界摇摆**。

## 六 · 结论与建议

### ✅ 功能层面：修复成功，无争议
- 英语真题从 **0 命中 → 8/8 命中**
- 域归属精确（189/190 分账清楚）
- 越域片段 **0**、auto 路由 **100%**、Hit@5 **100%**（34 条全进 top5）

### ⚠️ 指标层面：Hit@1 的 −2.9pt 是「口径与竞争格局」，不是退化
1. **不要拿 76.5% 当绝对基线** —— 它含**缓存口径红利**（+3.0pt）。真实基线是 **73.5%（冷重排）**。
2. **Hit@1 有 ±3pt 固有噪声**，单条排名（e01/m07/m12）在临界位置摇摆 → **看指标必须看 Hit@3/@5 与 MRR，别只看 Hit@1**。
3. `e01` 的下降说明 **expect 集跟不上新增资料** —— 与 m02 那次同源（"已入库≠可检索"第四种形态：**新资料入池挤位，评测期望未更新**）。
