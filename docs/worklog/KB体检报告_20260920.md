### 8.3 本次修掉的三个真缺陷

1. **Ollama 一停，整个 RAG 直接抛 requests 栈**，用户看不出是「索引坏了」还是「模型没起」。
   → 加 `ensure_ollama()`：没跑就自动后台拉起（等最多 30 秒），失败给人话提示后 `exit 2`；`--list` 列题模式不依赖它。
   - **附带坑**：环境里若设了 `HTTP_PROXY` / `HTTPS_PROXY`，`localhost:11434` 会被代理拦成 **502 Bad Gateway**，
     看着像 Ollama 崩了，其实是代理转发失败。诊断 Ollama 必须 `proxies={'http': None, 'https': None}`。
2. **重排缓存不认「分池换代」**：`cache\rerank_cache_v4.json` 的键不含 scope、也无版本盐 →
   改完分池实现后仍会命中旧条目，输出上一代逻辑的排序，极易被当成「新实现无效」。
   → 加 `RR_SALT`（改逻辑即 +1，现 `scope-v3`）并纳入 `scope`；旧缓存**改名保留**为
   `rerank_cache_v4.json.stale_20260920_scope`（不删除）。
3. **`auto` 路由只有二值**（course / all），考插第一优先级没体现。
   → 三路化：`考插/插班生/数学真题/英语真题/考试真题` → `kaocha`；技术词 → `all`；其余 → `course`。
