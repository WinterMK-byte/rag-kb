## 第 1 步（仅图片/扫描件需要）—— OCR

```bat
:: 先停 Ollama 腾内存（OCR 与嵌入不并行）
py -3.12 -X utf8 ocr_new.py "C:\Users\<you>\Desktop\Resource\新目录" 批次名
```
- 产出 `text_cache_批次名\sha1(绝对路径).txt`，**已带标题头**，`--text-cache` 指过去即可。
- 单 worker 串行；可用内存 < 3GB 自动停；**中断可续跑**（已完成的跳过）。
- 实测吞吐 ≈ 51 张 / 5.9 分钟。

## 第 2 步 —— 派生新库 v10（**不能原地改 v9**）

```bat
:: a) 复制 v9 → v10（5 件套一起，别从零建）
py -3.12 -c "import shutil,os,glob;src=r'C:\Users\<you>\Desktop\Marvis产出\本地知识库\vector_store_v9';dst=r'C:\Users\<you>\Desktop\Marvis产出\本地知识库\vector_store_v10';os.makedirs(dst,exist_ok=True);[shutil.copy2(f,os.path.join(dst,os.path.basename(f))) for f in glob.glob(os.path.join(src,'*'))]"

:: b) 建 force-list（把新文件绝对路径写进 json 数组）→ 见 mk_forcelist 用法或手写
:: c) 重嵌（--out 指 v10；--model 不传会自动沿用 v9 的 config.model = qwen3-embedding:0.6b）
py -3.12 -X utf8 build_kb_v3.py ^
  --root "C:\Users\<you>\Desktop\Resource" ^
  --root "C:\Users\<you>\Desktop\Marvis产出\RAG技术知识库" ^
  --out vector_store_v10 ^
  --text-cache "…\本地知识库\text_cache_批次名" ^
  --max-chunks 60 ^
  --force-list "…\本地知识库\v10_force.json" ^
  --report "…\本地知识库\v10_build_report.json"
```
**三个死穴**（`kb-ocr-backfill` skill 有详述）：
1. `--force-list` 是水印件/已有正文扫描件的**唯一**重嵌途径（增量只看 `has_text==False`）。
2. `--out` 必须指**已存在**的库（先复制），否则从零重建几小时。
3. 换库不传 `--model` → 维度冲突 `np.stack` 崩（现已支持自动沿用，但空目录从零建必须显式传）。

## 第 3 步 —— 域登记（**域外必做**）

新目录不在 `kb_search_v4.SCOPE_RULES` 的任何路径词里 → 落 `other` 域 → **默认 `core` 搜不到**。
```python
# kb_search_v4.py  SCOPE_RULES 对应基础域加目录名子串，例：
# 'kmath': (..., '院校B真题', '上交真题集', '新目录名'),
```
改完**必须同时升两个盐**（否则命中旧缓存，会把「改动无效」误判成事实）：
```python

kb_answer.py:     ANS_SALT = 'ans-v6'    # ⚠️ 局部变量，grep 找，别用模块属性访问
```
顺手把 `DEFAULT_VSTORE` 切到 `vector_store_v10`。
