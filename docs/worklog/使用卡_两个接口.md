## 二、考插接口怎么用

### 数学：优先「列题」，不要检索

考插数学真正的入口是**题目库 1832 题**（不走向量检索，秒级返回）：

```bat
py -3.12 -X utf8 kb_ask.py --list --kp 极限                 :: 极限 全部题目
py -3.12 -X utf8 kb_ask.py --list --kp 极限 --type 证明题     :: 极限 的证明题
py -3.12 -X utf8 kb_ask.py --list --kp 积分 --qtop 50        :: 最多列 50 条
```

- 交互模式下更短：`t 极限`、`t 极限 证明题`
- 知识点（14 个，**是子串匹配**）：极限 / 导数与微分 / 积分 / 定积分应用 / 中值定理与泰勒 / 微分方程 / 无穷级数 / 重积分 / 曲线曲面积分 / 多元函数微分 / 空间解析几何 / 线性代数 / 概率论与数理统计 / 其他
- 写「曲线积分」命中 0，要写「曲线曲面积分」

### 英语：走检索

```bat
py -3.12 -X utf8 kb_ask.py "四级段落翻译技巧" --scope en
```

⚠️ **考插英语没有题目库**——它只有词汇、完形、翻译、写作类讲义与真题（1456 片段），
所以英语走检索，数学走列题。

## 四、为什么必须分域（一句话）

考插和课业都讲「极限、积分」；不分域时，问课业的「能带结构」会被**英语考辅文档**顶到 top1
（实测 top1 = 「英语四六级考试段落翻译题.doc」）。分了域各找各的。

## 八、要「一句话答案」而不是 5 条片段 → `问答案.bat`

**双击 `问答案.bat`**（或 `kb_answer.py`）——这是**模范 RAG 入口**：
给它一个问题，它自己检索、自己判断证据够不够、不够就**换招再搜一轮**，最后给你一段
**带 [编号] 引用的答案**，末尾附上出处文件。资料里没有就直说没有，不编。

```bat
py -3.12 -X utf8 kb_answer.py "电子的能带结构是怎么形成的"
py -3.12 -X utf8 kb_answer.py "极限的定义" --scope math
py -3.12 -X utf8 kb_answer.py "四级段落翻译技巧" --scope en --json
py -3.12 -X utf8 kb_answer.py "PN结" --scope course --no-answer   :: 只要检索，不要答案
```

进窗口后直接打字 = 提问；`s math` 切域、`top 8` 改条数、`q` 退出。

**它比 `kb_ask.py` 多的东西**（这正是「模范 RAG」的做法）：
1. **Agentic 多轮**——第 1 轮证据不足时自动升级：① 换召回方式（关改写关重排，救被误杀的候选）② **扩检索域（`kmath → mathdoc → kaocha → core → gpa → all`，不再一跳到底）** ③ 在最佳文件里深挖更多块；
2. **带引用答案**——云端 `glm-5.2` 生成，失败自动回退本地 `qwen2.5:7b`，再失败就只给片段（不会卡死）；
3. **引用校验**——答案里越界的 [编号] 一律剔除，正文没有引用就自动附「来源清单」；
4. **拒答**——证据真的不够时说「资料里没有」，不硬编；
5. **答案缓存**——同样的问题第二次秒回（也给云端限流兜底）。

**考插数学问概念时**：直接问就行 —— 证据不足它会自动扩到 `mathdoc`（数学课件讲解）。
实测：「考插数学 函数的凹凸性和拐点怎么判断」第 1 轮在题目库里查不到 → 第 3 轮扩到讲解域，
命中 `ch4-2函数的凹凸性和拐点.pdf`（李莹课件，9.86 分）。想直接指定就加 `--scope mathdoc`。

⚠️ **比检索慢**：检索 2~8 秒，问答 10~40 秒（要等模型写答案）。**只要片段就用 `kb_ask.py`。**

## 九、让别的 Agent 接入这个知识库（MCP）

已经把它包成了 **MCP server**（`kb_mcp.py`），任何支持 MCP 的 agent（Claude Desktop / WorkBuddy / Cursor / 自建）都能直接调用。

**暴露 5 个工具**：`kb_search`（检索片段）/ `kb_ask`（带引用答案）/ `kb_list_questions`（考插数学列题）/ `kb_stats`（库存与各域分布）/ `kb_scopes`（域说明）。

配置已写进 `C:\Users\<you>\.workbuddy\mcp.json`（server 名 `local-kb`）。**但 MCP 不会自动生效**：

1. 打开 WorkBuddy → 连接器管理页 → **右上角「自定义连接器」入口**；
2. 找到 `local-kb`，点 **「信任」**；
3. 之后新会话里就能直接让它「查我的知识库」。
4. 前置：**Ollama 必须在跑**（和命令行入口同一个依赖）。

回退：删掉 `mcp.json` 里的 `local-kb` 段即可，不影响命令行两个接口。
