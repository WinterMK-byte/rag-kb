## 三、🔴 m02 的真正根因（比施工单/裁定件描述更深一层）

### 3.1 改 expect 没用 → 说明问题不在 expect

第 6 步改完 expect 后 m02 **依然未命中**。对比 `kb_ask.py` 的输出（rank=1 命中），
发现**同一问题在评测里和 CLI 里结果不同**：

| 入口 | 域 | top1 |
|---|---|---|
| `kb_ask.py` | auto → **`core`** | ✅ `Ch2-2-5无穷小的比较.pdf` |
| `kb_eval.py`（m02 标注） | **`kmath`** | ❌ `IMG_0254.jpg` |

### 3.2 逐域实测（决定性）

```
m02 期望 = ['Ch2-2-5无穷小的比较', '考研数学必备手册', '第3册解答']

scope=kmath    rank=-   [1] IMG_0254.jpg  [2] 第一篇：极限计算与应用篇.pdf  ...
scope=core     rank=1   [1] Ch2-2-5无穷小的比较.pdf  [2] Ch2-2-3无穷小和无穷大.pdf ...
scope=mathdoc  rank=1   [1] Ch2-2-5无穷小的比较.pdf  [2] Ch2-2-3无穷小和无穷大.pdf ...
```

### 3.3 三份期望文件的域归属

| 文件 | 基础域 | 在 `kmath` 内？ |
|---|---|---|
| **`Ch2-2-5无穷小的比较`**（真正讲这题的讲义） | **mathdoc** | ❌ **False** |
| `考研数学必备手册` | kmath | ✅ True |
| `第3册解答` | gmath | ❌ False |

**根因：m02 被标注为 `kmath`（考插数学域），但正确答案在 `mathdoc`（华理数学讲义域）→ 被域隔离挡住。**

- `kmath` 域内只 **12 段**含「等价无穷小」（全是题目碎片 / 真题）
- `core` / `mathdoc` 域内则含那份**真正讲等价无穷小的讲义**

### 3.4 这是「已入库 ≠ 可检索」的第三种形态

此前记录过两种：

1. 无正文（`has_text=False` / 水印）
2. 域外不可达（目录不在 `SCOPE_RULES`）

**新增第三种：评测集 `scope` 标注与真实答案所属域不匹配** → 检索被自己的域隔离挡住。

### 3.5 设计层冲突（需老板知悉）

评测集里 8 条 `mathdoc`（m07–m14）**全部命中**，说明「知识点讲解类」题的答案本就在 mathdoc。
而 m02（`等价无穷小替换公式有哪些`）与 m12（`无穷小和无穷大 比较 性质`，标注 mathdoc，命中）
**属于同一类题**，却被标成了 `kmath`。

→ 这不是「数据坏了」，是**评测集早期标注随手给的域**。改 `mathdoc` 后与 m12 同类一致。
