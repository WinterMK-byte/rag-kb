# rag-kb · 跑在自己电脑上的知识库

一套完整的**本地 RAG 知识库**：把散落的 PDF / 课件 / 真题 / 笔记变成一个能用自然语言提问、
给出带出处答案的系统，并且**自带评测**，让"改了有没有变好"这件事是可度量的。

> ⚠️ **这个仓库只含"方法"，不含"数据"。**
> 模型、课件原文、向量索引、题目正文都不在这里 —— 它们既大（4.9 GB）又有版权问题。
> 你拿走的是**搭这套东西的做法**，以及让别人卡在同样地方时能少走弯路的那 32 篇迭代记录。

| | |
|---|---|
| 规模 | 8618 个可检索片段 / 12 个检索域 / 冷档 Hit@1 79.4%（@3 97.1% · @5 100% · MRR 0.890） |
| 许可 | MIT |
| 姊妹项目 | [`wb-bot`](https://github.com/WinterMK-byte/wb-bot)（协作机制）· [`agent-workflow-sop`](https://github.com/WinterMK-byte/agent-workflow-sop)（协作流程） |

## 它解决什么问题

如果你试过"把一堆 PDF 塞进向量库然后问答"，大概率撞过这三堵墙：

1. **学科串味** —— 问「电子的能带结构」，返回「英语四六级翻译题」。
   原因不是模型差，而是**不同学科的中文片段在同一嵌入空间里挤成一团**。
2. **改了不知道好不好** —— 换嵌入模型、调 chunk 大小、加重排，全凭感觉。
   改完跑几个问题，"感觉还行"就上线了。
3. **新版反而更差，但发现不了** —— 因为从没有一段可重复的评分基线。

`rag-kb` 的答案分别是：**域隔离**、**评测集驱动**、**可复现的冷热双跑**。

## 快速开始

前置：`Ollama` 在跑（`ollama serve`），并已拉取嵌入模型与重排模型。

```bash
# 1. 装依赖
pip install -r requirements.txt

# 2. 把 .py / .bat 里的路径占位符换成你自己的
#    C:\Users\<you>  →  你的路径
#    <KB_ROOT>       →  知识库根目录
#    <DATA_ROOT>     →  你的原始资料目录

# 3. 建索引
py -3.12 build_kb_v3.py --root <DATA_ROOT> --out vector_store

# 4. 提问
py -3.12 -X utf8 kb_ask.py "多元函数偏导数 求偏导"

# 5. 要一句话答案（带 [编号] 引用与出处）而不是 5 条片段
py -3.12 -X utf8 kb_answer.py "多元函数怎么求偏导"
```

Windows 用户双击即可：`考插资料.bat` / `课业资料.bat` / `查资料.bat` / `问答案.bat`。

## 核心设计一：域隔离（这是最值钱的部分）

**同一个词在不同学科里意思完全不同。** 「极限」既是高数考点，也是物理概念，还出现在英语阅读里。
把它们装进一个池子，检索就是在抽奖。

所以这里把语料切成多个域，每个域独立检索，按问题自动选：

| 域 | 片段 | 装什么 |
|---|---|---|
| `core` | 2687 | **默认域**，日常检索用 |
| `kaocha` | 1701 | 升学备考数学 + 英语 |
| `gpa` | 5887 | 校内科目的全部资料 |
| `kmath` | 536 | 备考数学真题与讲义 |
| `mathdoc` | 410 | **讲解型**数学文档（课件 / 讲义 / 教案） |
| `all` | 8618 | 兜底全库 |

**`mathdoc` 这个域值得单独说。** 起因是发现题库里几乎全是题目（讲解型只有 61 个片段），
于是"这道偏导数题怎么做"能召回，但"偏导数是啥"答不好 —— 因为**题库不包含讲解**。
而学校那边的课件讲义覆盖同一套大纲、却躺在够不到的域里。加了这个域之后，
问概念的扩域链是 `kmath → mathdoc → kaocha → core → gpa → all`，理论上自动借讲解。

> ★ 一个反复踩到的坑：**"已入库" ≠ "可检索"**。
> 新加的目录如果没登记进 `SCOPE_RULES`，它会落到 `other` 域，而 `other` 不在任何别名里 ——
> 于是索引里有数据，但默认检索永远搜不到。这个坑这里栽过三次，见 `docs/worklog/`。

### 三档检索

| 档位 | 参数 | 代价 / 精度 |
|---|---|---|
| `fast`（默认） | `--mode fast` | 本地改写 + 召回 + 两阶段重排，10~30 秒 |
| `turbo` | `--mode turbo` | 只做向量 + 关键词召回，1~2 秒，精度低 |
| `deep` | `--mode deep` | 云端模型改写重排，约 1 分钟，需联网 |

## 核心设计二：评测驱动

改任何东西之前先问：**用什么证明它变好了？**

`qbank/` 里是评测用例（`查询 → 期望命中的文档`），`kb_eval.py` 跑出来是这个格式：

```
Hit@1  79.4%   Hit@3  97.1%   Hit@5  100%   MRR  0.890
```

★ **一条花了几周才学会的方法论**：

> **`--both` 在同进程里做"冷热一致"对比，不能证明跨进程可复现。**
> 同进程跑冷档和热档，测的是"同一个 Python 解释器里缓存有没有生效"；
> 真实使用者面对的是**下一次全新启动**。真检验必须**跨进程双跑**。

还有一条：**先校准尺子再量身高**。要测"负载会不会影响结果"，
前提是先确认"无负载时结果本身稳定" —— 否则整场实验没有意义。

## 数据层怎么准备（为什么这 4.9 GB 不在这个仓库）

| 层 | 体积 | 为什么不传 | 你怎么得到 |
|---|---|---|---|
| 嵌入 / 重排模型 | 2.1 GB | HuggingFace 上都有，且单个 `safetensors` >100 MB 会被 GitHub 拒收 | 自己 pull |
| 课件正文 | 1.6 GB | **版权** | 放你自己的资料 |
| 向量索引 `vector_store_*` | 0.43 GB | chunk 正文是上面资料的派生品，版权同源 | 跑 `build_kb_v3.py` 生成 |
| OCR 出的正文 | 0.64 GB | 同上 | 跑 `ocr_new.py` / `vl_ocr.py` |
| 题目正文 `questions_math.jsonl` | 1.2 MB | **原文** | — |

`.gitignore` 默认忽略 `models/`、`vector_store*/`、`text_cache*/`、`temp/`，
而且 CI 里还有一道 `tools/data_layer_check.py` 门禁专门盯着这件事 ——
**光靠 .gitignore 挡不住 `git add -f`**。

```
rag-kb/

├── *.bat                Windows 双击入口

│   └── data_layer_check.py  数据层没被误提交（5 项自测）
├── docs/
│   ├── 01-系统说明.md    完整技术文档（规模 / 结构 / 原理 / 维护）
│   └── worklog/         32 篇真实迭代复盘 ★
└── .github/workflows/   CI：隐私门禁 + 数据层门禁 + 语法检查
```

### 为什么把 worklog 全部公开

`docs/worklog/` 里是一个多月的密集踩坑实录（32 篇）：为什么换嵌入模型、为什么加这个域、
哪次改完重排结果反而变差、当时的实测数据是多少。

**这些才是真正不可复制的东西。** 代码别人能重写，"这条路走不通"的经验不能。
比如 `cos(极限, PN结)` 从 0.615 降到 0.379 这条记录，比任何 tutorial 都更能说明"为什么该换嵌入模型"。

## 隐私与脱敏

这个仓库是从一个**真实在跑的私人知识库**里抽出来的，所以发布前必须过工具，不能靠"我记得删了"。

```bash
python tools/privacy_check.py --selftest     # 先验判据本身对不对
python tools/privacy_check.py                # 再扫本仓库
python tools/data_layer_check.py             # 确认数据层没混进来
```

已处理项：本机绝对路径 → `<KB_ROOT>` / `C:\Users\<you>`；语料来源机构名 → `院校A/B/C`；
`questions_math.jsonl` 等含原文的文件**整个剔除**，评测用例只留查询与命中关系。

★ 另外有一类容易被漏掉的：**AI 辅助编辑过的文档会留下溯源元数据**。
这里 3 个 md 的 YAML front-matter 里原本带着一个 21 位平台账号 ID 与两段加密串 ——
**任何关键词词表都抓不到它**，因为里面没有密码、没有邮箱，只有"这段不需要公开的元数据"。
已剥离。
（注：本句刻意不复述那个 ID —— 在"已删除"的说明里把原值再贴一遍，是最常见的自打脸。）

## 已知问题

- 本地 7B 重排器**偏关键词**：问「电子的能带结构」会把「示波器实验报告」（都含"电子"）顶高；
  换成带术语的提问（「PN结的形成原理」）就正常。
- `--mode deep` 依赖云端 API，断网时不可用。
- 脚本里的路径需要从占位符替换成实际路径（一次性工作）。
