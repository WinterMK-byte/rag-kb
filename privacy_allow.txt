# 项目级脱敏豁免清单
#
# 格式：
#   · 一行一个**正则** —— 匹配到的片段在扫描前被剥掉
#   · 以 `EXT:` 开头的行 —— 声明「这个扩展名不算可疑文件」
#   · `#` 开头是注释
#
# ★ 规矩：每一条豁免**必须写明理由**。
#   没有理由的豁免 = 给自己开后门，日后必然假绿。
# ---------------------------------------------------------------------------

# ① 分词相关术语不是凭据
#    `max_tokens` / `tokens` / `tokenizer` 是各家大模型 API 的标准参数/术语，
#    出现在代码里恰恰说明它属于**公开协议的一部分**，不是密钥。
#    注意写法：不能用 `\btokens\b` —— `max_tokens` 里 `_` 和 `t` 都是单词字符，
#    `\b` 在那里**不成立**，规则会失效（实测连踩两次）。前后只判"是不是字母"。
(?i)(?<![A-Za-z])tokens?(?![A-Za-z])
(?i)tokeniz(?:e|er|ed|ing)

# ② 密钥读取函数的定义与调用形态 —— 出现 api_key 是正常的
(?i)def\s+_?api_?keys?\b
(?i)_?api_?keys?\s*\(\s*\)

# ② 从环境变量读取密钥 = 没有硬编码的证据
#    `def _api_key(): return os.environ.get('SENSENOVA_API_KEY')` 里出现 api_key 是正常的，
#    文件里**不存在任何密钥本身**。反之，若真写出 `api_key = "sk-..."`，会被 ⑤ 抓住。
(?i)\bapi_?keys?\b(?=\s*[:=]\s*(?:os\.environ|getenv|None|""|''))
(?i)os\.environ\.get\(\s*['"][A-Za-z_]*API_?KEY

# ③ Windows 标准路径段 —— 任何人机器上都有，不构成身份信息
AppData\\(?:Local|Roaming)\\

# ④ 日期形态（YYYYMMDD / YYYY-MM-DD / YYYY/MM/DD）
\b20\d{2}[-/]?\d{2}[-/]?\d{2}\b

# ⑤ 环回地址 —— 本机服务（Ollama 默认端点），不是内网资产
#    真正的 10.x / 192.168.x / 172.16-31.x 依然会被拦。
https?://(?:localhost|127\.0\.0\.1)(?::\d+)?

# ⑥ .bat 是本项目的 Windows 双击入口，不是可疑可执行文件
EXT:.bat

# ⑦ 纯数字串：8~19 位太常见（日期 / 时间戳 / 短 ID）→ 只有 ≥20 位才提示
#    真身份证(18)/卡号(16~19) 靠 §② 的专用正则抓，不靠长度。
(?<!\d)\d{8,19}(?!\d)
